# 2026-10-30

## 新增：小目录跳过功能（skip-under）
需求：文件夹内容 < 600 MB 时跳过，不做分箱。

改动：
- `config.py`：新增 `SKIP_UNDER_MB = 600`（0 表示关闭）。
- `main.py`：
  - `FolderPlan` 增加 `skipped` / `skip_reason` 字段。
  - `build_folder_plan()` 增加 `skip_under_bytes` 参数，`scan.total_size < skip_under_bytes` 时直接返回空计划并标记跳过。
  - 新增 CLI 参数 `--skip-under N`（默认 600，`0` 关闭）。
  - `render_preview` / `print_summary_block` / dry-run JSON 输出相应展示跳过信息。
- `gui/app.py`：参数区新增「跳过阈值 (MB)」输入框 + 「内容小于阈值时跳过」勾选，默认开启；`_params()` 改为返回三元组 `(target, max_bytes, skip_under)`。
- `tests/smoke_test.py`：受影响用例（resume/undo/over_target/json/readonly）补 `--skip-under 0`；新增 `case_skip_under` 用例。41/41 通过。
- `README.md`：文档补充 `--skip-under` 说明。

约定：跳过判断用「严格小于」（`<`），600 MB 整不算跳过。
